Documentation for kachemak Bay intertidal data analysis tool - NMDS

Github: https://github.com/hig314/low_tide

An NMDS plot shows similarity between surveys, specifically it treats each survey as a point in many-dimensional space where each dimension is a species and then compresses it down to a 2d plot while attempting to preserve distance order.

If neither shapes nor colors is set to locations binning will simply bin all surveys in the timeframe together, if either one is set to locations binning will separate the locations into separate point

Some data points have a numerical range instead of an exact count, these are treated as a number by the tool but the real value can be accessed by mousing over a point.
Main ranges and the numbers they are displayed as:
• 5-10: 7
• 10-20: 15
• 20-100: 40
• >100: 100
Some species are also collected as presence-absence, this is treated as a 0 unless the data-transformation menu is set to presence-absence. All coastal studies data is presence-absence so present is treated as 1 for that data even in numbers.

“Requires standard group” makes it only include surveys that all 3 of our main data collectors were present, it does not work for coastal studies data.

The temperature is water temperature taken from https://api.tidesandcurrents.noaa.gov/api/prod/ and averaged over the day, it is only displayed at the day of a survey.

Scientific names are the most precise id we could confidently get, in many cases we believe the group we are referring to is more precise than the one in the scientific name but could not actually get a better id.

Biodiversity is the number of species observed within the current category.

“Odd phylums” refers to bryozoans and brachiopods.

All squishy molluscs, e.g. octopus and pteropods, are included with nudibranchs.
